# Pilot handoff

Carry the generated `BC-CAJA-PILOT-001.zip` to the pilot PC. Extract it and preserve the complete `BC-Caja` directory. Execute `BC-Caja.exe`.

Application updates replace only the extracted `BC-Caja` application directory. Never delete, copy over or relocate `%LOCALAPPDATA%\BC\Caja`, which contains the production database and backups.

Tester: follow `PRODUCT_TEST_CHECKLIST.md` and classify findings as `BUG`, `UX`, `MEJORA`, `IDEA` or `NO ACCIÓN`.
