# Installation

1. Copy the entire `BC-Caja` folder from the pilot ZIP to the optical-store PC.
2. Open that folder and run `BC-Caja.exe`.
3. Optionally create a desktop shortcut to that executable.

No Python installation or Internet connection is required.

Data is automatically created under `%LOCALAPPDATA%\BC\Caja`, never inside the application package.

For future updates, replace only the application folder. Never copy, delete or overwrite `%LOCALAPPDATA%\BC\Caja`.
