# PX-Core

## Descripción

PX-Core es el sistema principal de Proyecto X.

Su objetivo es administrar todo el crecimiento del proyecto, registrando el progreso, las ideas, los proyectos, las tareas, las horas invertidas y las estadísticas.

---

## Objetivo de la primera versión

Crear una aplicación web sencilla que permita:

- Gestionar proyectos.
- Gestionar tareas.
- Registrar horas de trabajo.
- Guardar ideas.
- Registrar objetivos.
- Mostrar estadísticas.
- Llevar un diario de avances.
